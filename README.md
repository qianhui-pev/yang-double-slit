## 说明

这是**课程作业**（大学物理 · 杨氏双缝干涉与光程相干性），用来交作业和课堂演示。

页面**基本由 AI 完成**：我用 Hermes Agent（Nous Research）把需求、方向和验收标准一条条说给它，代码、文案、排版与动效都由它写。我做的是——定选题与方向、分阶段下指令、看截图和实测数据决定留哪条删哪条；物理模型、题库和判定逻辑它都附了实测核对记录（见 `HANDOFF.md`）。

技术上是**单个 HTML 文件**：零外部依赖、字体已按用字子集化内嵌、断网可用；没有使用任何第三方模板或 UI 库。

单文件 Web 应用（无外部依赖、可离线跑）。选题：**杨氏双缝干涉 + 光程与相干性**。

- 入口页改为满幅光场：画布铺满整屏，文字压在左侧渐变护罩上；右上角 LIVE 仪表实时显示 λ / d / L / Δy。
- 光场渲染：filmic 色调映射 + 白核收敛 + 三层辉光（叠加 alpha 压在 1 以内，避免叠成白）；屏带 26px 缓冲 + 余弦软边；Δλ>0 时按三波长取样，场里也能看到条纹塌陷。

## 物理模型与边界
- Δy = λL/d，δ = d sinθ（严格）/ δ ≈ d·y/L（小角）
- 时间相干：V_t = |cos(π Δλ δ / λ²)|，L_c = λ²/Δλ
- 空间相干：V_sp = |sinc(π b d /(λ R))|，b临界 = λR/d
- 显示层把缝距放大到可见尺度，读数面板始终用真实量纲；画布左侧标有说明

0. 一句话现状

杨氏双缝教学网页（单文件、内联字体、断网可用、手机可用），六个学生步骤 + 口令控制台，功能与文案都已定稿并验收过；剩下要做的只有「视觉/动效」这一层。 当前调性是 暗室光学仪器 + 档案纸：深色冷调机械线 + 单一暖色激光红 + 衬线大标题 / DIN 仪表字 / Castellar 罗马数字三种语气。

1. 硬约束（违反就退回）

  1. 单文件交付：dist/index.html 一个文件，零外链、零 CDN、断网可跑。新依赖必须内联（字体同理，build.py 会自动子集化并打印缺字）。
  2. 不引第三方动效库（anime.js / framer-motion / GSAP 一律不用），全部手写 CSS/Canvas。
  3. 仪器感优先：用户原话「要高级感不是花」。位移 ≤1px、时长 ≤180ms（表格展开 420ms 除外）、一次性动效不循环、不加常驻背景动画。
  4. 物理不能为了好看改错：显示层可放大尺度，读数面板必须真量纲。
  5. 每个新增效果都要能一键关掉（建议统一 ?fx=0 或 body[data-fx="off"]）。
  6. 尊重 prefers-reduced-motion。

3. 「效果明显不明显」的判断线（先定标准再动手）

用户原话：「你说的那些我不知道实际上效果明显不明显」。所以每个效果交付必须带前后对比 + 数值，按下面阈值判断，达不到就换方案：

观感维度 肉眼可辨的最低量 说明
亮度差 ΔL ≥ 12/255 暗场里更敏感，低于 10 基本无感
色相差 ΔE ≥ 15 光谱 / 波长类靠这个判
帧间变化 差异像素 ≥ 3% 光扫、余晖、幽灵条纹靠这个
位移 ≥1px（本设计要求 ≤1px） 所以别靠位移，靠亮度 / 色彩 / 时长
时长 100–180ms 最舒服 >400ms 显拖沓，<60ms 看不见
循环 只做一次性 循环＝廉价感

交付格式：同参数的 前/后 PNG（裁同一块）+ 2–3 秒 GIF + 一行数值（ΔE / 帧差占比 / 衰减曲线）。

4. 动效 / 光效清单

第 1 批（都在现有文件里改，单条 ≤1 小时，风险低）

V1 入口「光斑照字」 做法：fx.js 第 6 段已有指针牵引光晕（写 --lx/--ly）。用同一组坐标做遮罩层：光斑内文字提亮到 --ink-0，其余压到 55%，径向 22% 软过渡，跟随延迟 40ms。 为什么明显：文字区 ΔL 能到 30+，且覆盖整个标题区。 验收：量「光斑中心 120px 内平均亮度」与「左侧同高边缘」之差 ≥12；GIF 3 秒。 风险：与 .stage__scrim 抢层，注意 z-index（scrim 在画布上、文字下）。

V2 光谱取样器（最看好的一条） 做法：λ 滑杆轨道改成 380–780 nm 真实光谱渐变（CSS 12 个色标）；拖动时滑块下方浮出当前 λ 的窄带（±2nm）与色块；光场颜色随 λ 连续插值（optics.js 现在取离散色，改成按 λ 求值 + 120ms 缓动）。 为什么明显：整幅光场换色，ΔE 轻松 30+，而且这是物理上本来就该有的效果。 验收：λ=405 / 532 / 632.8 / 700 各截一张，取屏带中线平均色，相邻两张 ΔE ≥15；GIF 拖滑杆。 风险：逐像素渲染里别每帧重算取色，缓存色值表，λ 变才重算。

V3 幽灵条纹（参数变化的记忆） 做法：滑杆 handler 里，参数变化时把当前画布 drawImage 到离屏 canvas，作为幽灵层 35% 不透明度叠 1.2s 后淡出（rAF 里做 alpha 衰减）；只对 d / λ / L 启用。 为什么明显：改 d 时条纹「长/缩」被可视化，帧差 3–8%。 验收：同区域改参数前后各截一帧，帧差 ≥3%；1.2s 后残留 <0.3%。 风险：与磁吸联动会每帧触发，需 120ms 节流；单光子模式别启用。

V4 单光子余晖 做法：photon 模式改两层 —— 永久累积层（alpha 0.18）+ 活跃层（最近 1.5s，亮度按 e^-t/0.6 衰减），每帧只重绘活跃层。 为什么明显：能看见「曝光正在发生」，并让概率分布更可信。 验收：固定区域取 0 / 0.5 / 1.5s 三点亮度单调下降；累积 2000 光子后与理论 cos² 曲线相关系数 >0.9（canvas 像素取样算）。 风险：叠加层 alpha 总和必须 <1（否则死白，见坑 3）。

V5 数字滚动（只两处） 做法：.read__v 的「条纹间距 Δy」「该点 δ」值变化 120ms 插值滚动（rAF + tabular-nums 防抖宽），别全站铺。 验收：拖滑杆截两帧能看到中间态数值。

第 2 批（改动稍大，观感更整）

V6 屏带材质：亮纹偏暖 #FFB27A、暗纹偏冷 #0B1A26，条纹边缘 1px 柔化。验收：亮纹像素 R−B ≥25。风险：会与现有的「波长→颜色」映射打架，两处要配套改。

V7 换页揭幕升级：.beam-wipe 改成沿光轴方向（左→右）扫过并留 0.15s 拖尾。验收：帧差 ≥3%，总时长 ≤220ms。

V8 入口 HUD 联动：HUD 的 λ 是装饰漂移（622±62 nm 正弦）；给 Δy 加数字滚动，让「仪表在跑」更明显。

第 3 批（物理向，用户没点名但最值）

B1 单缝衍射包络 + 缺级：新增第 7 个参数「缝宽 a」，屏上强度 cos²(πδ/λ) · sinc²(πa y/(λL))；推到临界时出现缺级（某些亮纹直接消失）。改：physics.js 加参数与公式、optics.js 加包络、views-lab.js 加滑杆与读数、任务预设与文案同步。验收：数亮纹条数（9→6 这种整数变化）。风险：params.a 新字段，旧存档要默认值。

B2 数据舱：曲线模式旁加「Δy–d」小图，每次「记录」自动落一个散点，画 1/d 拟合线 + R²。验收：记录 5 组后 R² 显示、散点落在线上。

不建议做（会破坏仪器感）

粒子飞舞 / 常驻背景动画 / 玻璃拟态卡片 / 3D 透视卡片 / 满屏鼠标拖尾 / 大面积 blur 玻璃 —— 在深色仪器风里会立刻变成「网页模板感」。

5. 施工规范

  • 新样式写在 refine.css 末尾新开一节（现在到第 26 节）。
  • 只用现有 token：--void / --bg / --panel / --rule / --rule-soft / --rule-hard / --ease / --ink-2..4 / --laser / --jade / --amber。
  • 动效只用 transform / opacity / filter，别改 width/height/top/left（触发布局，手机掉帧）。
  • 画布层：亮度 0–190 必须 /255 再乘通道；多层叠加 alpha 总和 <1；不要在画布上写字（用户明确反感过「神秘文字」）。
  • 加新中文会改变字符集 → 必须重跑 build.py 并看缺字打印（站酷小薇缺 34 个数学符号是已知可接受）。
  • 手机 ≤820px 的样式集中在第 25 节，新按钮记得加热区。
  • 每个效果都加 data-fx 开关，便于 A/B 与回退。

7. 已知坑（完整版见 HANDOFF §6）

  1. 用户名带撇号：bash -c "cd …" 直接炸；用 execute_code + subprocess(cwd=…) 与 io.open。
  2. 浏览器标签页在两次调用之间会回到 about:blank：每次调用先 goto_url，并先 Emulation.setDeviceMetricsOverride，否则 elementFromPoint 为 null、点击全打空。
  3. canvas 上别写字；多层叠加 alpha <1；亮度要 /255。
  4. .view-in 带 animation … both 会把 position:fixed 关进页面坐标。
  5. 定宽子元素会撑破栅格而 scrollWidth 仍显示正常 → 越界检查要连容器内滚动一起看。
  6. input[type=range] 的 CSS 别写 !important（会压掉 fx.js 每帧写的填充渐变）。
  7. 动画简写里两个时间值 = duration + delay，容易写出「永远停在 0%」。
  8. 内联 style 里的 font-family 必须用单引号。
  9. 固定 FAB + 满高侧栏 = 结构性重叠；实验台已隐藏 FAB，改由面板按钮开抽屉，别放回去。
  10. 改文案 / 加中文 → 必须重跑 build，否则新字回落系统字体。
  11. 别改 core.js 存档格式；选项已做过轮转（window.BankRot / LabRot），旧存档 ans 索引会对不上，测试前先「清空本机」。

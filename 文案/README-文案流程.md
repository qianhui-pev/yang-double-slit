# 文案改稿流程（给你用的，不用命令行）

工程里所有面向学生的文字都抽成了一张表：**`文案/文案清单.html`**（双击打开，673 条，218 条长文案）。
每条都有固定 ID（C-001 … C-673），改稿时拿 ID 说话即可，不用碰代码。

## 三种改法，任选

### A. 最省事：告诉我「ID → 新文案」
例：`C-037 改成「持有口令即可查看。」`、`C-120 删掉不要`。
我按 ID 精确定位、替换、重新打包，并把清单同步刷新。一次给我一批（10–30 条都行）。

### B. 你直接改表，双击一个 bat 生效（自己动手）
1. 打开 `文案/strings.json`（记事本 / VS Code 都行，UTF-8）。
2. 找到要改的条目，把 `"新文案": ""` 里的引号中间填上你的新文字。**只填这一处，别的别动。**
   - 标了 `"含标记": true` 的条目里嵌着 HTML（加粗、换行、数字变量），自动应用会跳过它们，改这些发我。
3. 存盘，双击 **`文案/重写文案并打包.bat`**：
   - 先备份 `src/` 到 `文案/backup/<时间戳>/`
   - 逐条校验原文那句「在源码里恰好出现几次」，有一条对不上就**整体放弃、一个字都不改**
   - 全部通过后写回源码 → 重新构建（字体会按新文案重新子集化）→ 覆盖 `docs/` → 重打 zip
4. 反悔：双击 **`文案/回退上次文案.bat`**，还原上一版并重新打包。

> 第一次用之前如果提示 `没装 fontTools`，双击一次 `文案/安装构建依赖.bat`（走清华镜像装 fonttools + brotli），之后就不用管了。

### C. 只想先看 / 只改某几页
`文案/文案清单.html` 顶部有三个筛选：**全部 / 只长文案 / 带语气标记**，还有一个搜索框（可搜「其实」「只要」「请」这类词）。表里：
- `含排版标记` = 这句里夹着 HTML，改文字要顺手保住标记（发我更稳）
- `祈使` / `解释` / `鼓励` / `断言` = 自动扫出来的「说教味」嫌疑词（48 条），优先处理这些

## 文件都在 `文案/` 里
| 文件 | 作用 |
|---|---|
| `文案清单.html` | 全部文案的可读清单（带筛选/搜索） |
| `strings.json` | 改稿表，只填「新文案」 |
| `apply_copy.py` | 应用 + 构建 + 打包（可加 `--dry` 只预演） |
| `rollback_copy.py` | 还原上一版备份并重新打包 |
| `gen_inventory.py` | 重新扫源码、刷新清单（会保留你已填的新文案） |
| `template.html` | 清单页的样式模板 |
| `backup/` | 每次应用前自动备份的 `src` |
